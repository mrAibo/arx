# ARX v0.25.1

v0.25.1 is a focused usability and reliability patch over v0.25.0. It keeps the same Linux x86_64 target, Rust 1.88 MSRV, dependencies, configuration, and provider/runtime safety boundaries.

## Changes

- Preview archive members with F3 through the existing bounded preview path.
- Extract one focused regular archive member to a Local destination with F5, preserving names with spaces and rejecting unsafe paths.
- Keep action feedback visible until the next user input.
- Make TUI controls respond without per-event delay, keep footer hitboxes aligned with visible controls, and improve terminal contrast.
- Replace graphical job and status glyphs with ASCII markers for PuTTY and bare-terminal compatibility.
- Report terminal I/O failures as a concise error with exit status 1 instead of a panic/backtrace.
- Add a reusable physical UX acceptance harness for terminal behavior.

## Installation

Download the tarball, Debian package, or RPM plus `SHA256SUMS` from this GitHub Release, then verify:

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

No configuration migration is required from v0.25.0.
