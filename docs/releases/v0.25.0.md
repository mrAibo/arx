# ARX v0.25.0

v0.25.0 is the focused **WebDAV transaction surface** release. It publishes the
already accepted post-v0.24 work for recursive WebDAV → WebDAV Copy,
multi-root recursive WebDAV Delete, and verified WebDAV → WebDAV Move while
retaining the same exact provider-native identity, bounded planning, singular
runtime/Job authority, and no-blind-retry recovery model.

MSRV remains **Rust 1.88**. ARX remains Linux-only with the published
**Linux x86_64** target. No configuration migration is required from v0.24.0.

The immutable tag and live GitHub Release remain authoritative for actual
publication; source-tree version metadata alone does not imply that a release was
published.

## Highlights

### Recursive WebDAV → WebDAV Copy

ARX can copy one exact current-listed WebDAV collection to one new WebDAV root on
the same configured target or a different target.

- Provider-native `WebDavCollectionRef { target, href }` is the source authority.
- A complete bounded source manifest is built and revalidated before mutation.
- Same-target and cross-target use the same bounded WebDAV → ARX → WebDAV
  streaming path; ARX does not pretend cross-target work is server-side COPY.
- The new destination root is noclobber/attempt-owned.
- Ambiguous destination mutation is never blindly replayed.
- Full success requires an independent destination scan and manifest verification.
- Failed attempt-owned cleanup or unresolved mutation certainty becomes
  `RecoveryRequired`.

Accepted through #275 / PR #276.

### Multi-root recursive WebDAV Delete

F8 can delete one or more exact selected current WebDAV collection roots through
one existing mutation job.

- Selection freezes exact current-listing provider identities; display names are
  never delete addresses.
- Complete aggregate planning and whole-batch revalidation happen before the
  first DELETE.
- The aggregate plan is bounded to 50,000 planned items and is enforced while
  manifests are accumulated.
- Roots execute deterministically and sequentially.
- Descendants remain child-first/root-last, with a fresh exact Depth:1 empty proof
  before every collection DELETE.
- Global item progress, cancellation, definitive partial failure, and recovery
  state remain truthful.
- An ambiguous DELETE is issued once, immediately becomes `RecoveryRequired`, and
  is not replayed.

Accepted through #277 / PR #278.

### Verified WebDAV → WebDAV Move

F6 can move exactly one current-listed WebDAV collection to a new same-target or
cross-target WebDAV root through the explicit transaction:

`freeze source → bounded copy → independently verify destination → revalidate source + destination → delete exact already-frozen source manifest`

Copy completion alone is never Move success.

- The copied source snapshot and the destructive delete snapshot must describe the
  same exact identity set before destination mutation starts.
- Source drift before the first source DELETE leaves source untouched.
- Destination drift or unresolved destination certainty prevents source deletion
  and requires recovery.
- Source deletion consumes the already frozen manifest through the existing
  `MutationService` delete authority; it cannot silently absorb newly appeared
  source content.
- Once the first source DELETE succeeds, the verified destination is committed and
  is never rolled back.
- Definitive partial source deletion is `NeverRetry`; ambiguous source deletion is
  `RecoveryRequired` with no replay.
- One stable item unit covers the Move transaction so queue progress never changes
  units mid-attempt.

Accepted through #279 / PR #280.

### URI identity interoperability correction

Authoritative Apache acceptance exposed that servers may vary only the hex-digit
case of valid percent escapes. Canonical URI matching therefore treats forms such
as `%C3%A9` and `%c3%a9` as equivalent while **never** percent-decoding path
bytes, collapsing separators, or dropping query identity. Server-returned/raw
href identity remains authoritative after matching.

## Safety boundaries retained

- `ProviderRegistry` remains the single provider authority.
- `TransferQueueRuntime` remains the single transfer scheduler/runtime.
- `JobManager` remains lifecycle truth.
- Provider-native existing-resource identity remains authoritative.
- Ambiguous remote mutations are never blindly replayed.
- Successful transfer/executor return is not substituted for independent
  destination verification.
- WebDAV recursive Copy/Move remain new-root/noclobber operations; no merge,
  update, overwrite, or mirror semantics are implied.
- WebDAV Move remains one collection root only; no multi-root Move is implied.
- WebDAV automatic HTTP mutation retry remains disabled.
- S3 Inspector remains read-only and does not receive fabricated POSIX capacity
  semantics.

## Retained from v0.24.0

v0.25.0 retains SFTP → SFTP Workspace Sync from v0.24.0, including same-host and
cross-host Compare → Preview → Execute → Verify behavior with bounded remote → ARX
→ remote streaming and real two-endpoint OpenSSH physical acceptance.

It also retains the read-only S3 Object & Bucket Inspector from v0.23.0 and the
Local↔WebDAV recursive upload/download plus multi-root F5 Copy surface shipped in
v0.22.0.

No configuration migration is required from v0.24.0.

## Not in this release

- Multi-root WebDAV → WebDAV Move.
- Recursive WebDAV → WebDAV overwrite/merge/update/mirror semantics.
- File or mixed file/directory WebDAV Move.
- SFTP → SFTP Move or general cross-provider Move beyond the verified one-root
  WebDAV transaction described above.
- S3 synchronization or mutation expansion.
- Digest/Bearer WebDAV auth without concrete interoperability evidence.
- Metadata/property mutation without a demonstrated admin use case.

## Installation

Download your preferred artifact and `SHA256SUMS` from the GitHub Release and
verify:

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

```bash
# Debian / Ubuntu
sudo apt install ./arx_0.25.0_amd64.deb

# Fedora / RHEL family
sudo dnf install ./arx-0.25.0-1.x86_64.rpm

# Portable tarball
tar xzf arx-v0.25.0-x86_64-unknown-linux-gnu.tar.gz
sudo install -m 755 arx-v0.25.0-x86_64-unknown-linux-gnu/arx /usr/local/bin/arx
```

Expected version output:

```text
arx 0.25.0
```

No configuration migration is required from v0.24.0.
