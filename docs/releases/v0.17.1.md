# ARX v0.17.1

Patch release over v0.17.0. **Reliability / hardening only** — no new user-facing
features, no MSRV change (stays Rust 1.88), no backend scope changes.

This release folds in **PACK C** (post-v0.17.0 Remote Edit reliability
hardening), which landed on `main` via PR #155 (merged 2026-08-18).

## Remote Edit reliability (PACK C, issues #47–#53)

- **Transport-only SFTP invalidation (#47)** — a pooled SSH/SFTP connection is
  invalidated **only** for transport-level failures. Non-transport errors no
  longer tear down a healthy session.
- **Bounded pooled-session health probe (#48)** — before reusing a pooled
  session, ARX runs a bounded health probe with a fixed timeout. Stale or
  unresponsive sessions are discarded and reconnected exactly once.
- **Deterministic stale replacement / no destructive replay (#48, #50)** — the
  reconnect path is covered by a deterministic (no-network, no-sleep) test
  matrix proving: healthy reuse, stale detection, single fresh reconnect, and
  that a mutation runs exactly once (no replay spin).
- **Remote Edit lifecycle integrated with Job Manager (#51)** — the Remote Edit
  now flows through the shared `JobManager` + `job_events` channel. Typed
  `RemoteEditPhase` / `RemoteEditOutcome` events are emitted across
  download → editor → writeback, so a remote edit is observable and never leaks
  as `Running`.
- **Lane-isolated failure handling (#51/MAJOR)** — a generic `EffectEvent::Failed`
  on a **non-RemoteEdit** lane (e.g. LeftPane, GlobalProcess) reports the
  failure normally and does **not** mutate an unrelated in-flight Remote Edit's
  job, ownership, or lifecycle.
- **Deterministic fault-injection suite (#50)** — stage/backup/commit/verify
  paths are exercised with injected faults; recovery evidence
  (`RecoveryRequired`, `CommittedWithWarning`) is truthful, never fabricated.
- **Writable non-sticky parent safety (#53)** — a writable remote parent
  directory **without** the sticky bit is rejected fail-closed; a sticky parent
  is accepted. Verified by physical tests (provider reads under a 0o777 parent
  are also refused by design).

## Frozen invariants (unchanged)

- **SFTP Remote Edit**: regular files only; size limit unchanged; UTF-8 only;
  binary/NUL refused; conflict-safe; mode/UID/GID preservation;
  stage → backup → commit → verify; truthful `RecoveryRequired` /
  `CommittedWithWarning`; no destructive retry; no cross-lane lifecycle
  corruption.
- **S3**: no new capabilities; no secret fields; AWS + MinIO SUPPORTED MVP;
  Moto EMULATED; R2 / Wasabi UNVERIFIED.
- **SSH Manager**: no scope changes; no private key bytes in config or logs;
  managed `~/.ssh/arx_hosts.conf` model unchanged.
- **Local / Archive / Workspace**: no regression.
