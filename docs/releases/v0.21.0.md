# ARX v0.21.0

v0.21.0 ships the first recursive WebDAV capability — exact collection traversal to
Local — on top of the post-v0.20.0 correctness and interoperability work. MSRV
remains **Rust 1.88**; ARX remains Linux-only with the published **Linux x86_64**
target.

## Highlights

### Exact WebDAV recursive download (WebDAV → Local)

One selected WebDAV collection can now be copied to one new Local directory tree
through the existing F5 → `TransferPlanner` → transfer queue → WebDAV executor
authority.

- Traversal uses exact provider-native `WebDavCollectionRef` / `WebDavObjectRef`
  href identity. Presentation names never reconstruct remote addresses.
- Recursive discovery uses bounded authenticated `PROPFIND Depth: 1`; there is no
  `Depth: infinity` request.
- The complete remote manifest is built and validated before any Local mutation.
- Every Depth:1 result is proven a direct descendant of the traversed collection
  inside the configured target root, using canonical parsed wire URLs.
- Collection cycles, repeated canonical collection URLs, duplicate exact child
  identities, File/Collection trailing-slash conflicts, and duplicate Local
  presentation names fail closed.
- One server presentation name must map to exactly one safe Local path component;
  `/`, `\`, `:`, NUL, dot names, empty names, and absolute shapes are rejected
  without sanitization.
- Absolute raw hrefs are containment-checked on their real serialized path — a
  query can never impersonate the URL path — and encoded `.` / `..` / `%2F` /
  `%5C` path hazards are rejected.
- Exact streamed downloads resolve through the same exact-href authority:
  queries and existing percent encoding reach the server verbatim (no
  double-encoding), never reconstructed from display names or logical paths.
- The Local destination root is created only when absent (`create_dir`, never
  `create_dir_all`); an existing root fails closed untouched.
- Files reuse staged noclobber WebDAV download semantics; empty directories,
  Unicode/spaces names, and zero-byte files are preserved exactly.
- On failure or cancellation the attempt-owned Local root is removed; if cleanup
  itself fails the error carries the exact partial path and is classified
  recovery-required rather than blindly retried.
- Progress stays whole-attempt cumulative bytes with checked arithmetic; no
  saturated or fabricated samples, no new progress unit.

### WebDAV interoperability and correctness carried into this release

These correctness fixes landed after v0.20.0 and are part of this release:

- **WebDAV F5 target truth (#247):** Copy binds to the active pane's real source.
  Selection wins over cursor only when it resolves against the current listing;
  stale, ambiguous, synthetic, or multi-selected sources fail closed before any
  enqueue or provider execution.
- **MOVE Depth interoperability (#243):** MOVE no longer sends `Depth: 0`;
  COPY retains `Depth: 0`.
- **Nextcloud/ownCloud certification (#245):** Nextcloud 34.0.2-apache and
  ownCloud 11.0.0 pass the full I1–I12 physical matrix, including auth, nested
  MKCOL navigation, Unicode/space names, bounded preview, upload/download,
  COPY/MOVE, delete, and noclobber conflict behavior. Both are now certified
  targets alongside Apache mod_dav (W1–W18).
- Recursive download is physically accepted on Apache mod_dav, Nextcloud, and
  ownCloud through the identical product path.

### Post-v0.20.0 product work also included

- **Split panes:** horizontal mode, explicit close, keyboard ratio resize, and
  section-aware same-location mouse behavior.
- **Effective keymap:** conflict-safe effective keymap with `arx --print-keymap`
  exposing resolved bindings.
- **tmux/screen lifecycle hardening:** typed GNU Screen discovery plus terminal
  mode release/reacquire around interactive attach.
- **Mouse follow-up:** visible-row-correct clicks, drag selection, active-pane
  wheel, Shift+Click ranges, and provider-aware typed context menu.
- **Transfer pause stability:** deterministic pause physical acceptance.
- **Typed local Quick Actions:** added SHA-256, Touch, and Compress-to-tar.gz as
  typed local actions; the pre-existing mkdir/chmod/symlink surface remains
  available. The new actions avoid shell-string interpolation.

## Safety boundaries retained

- Destructive workspace sync still requires Preview.
- Transfer retry remains phase-aware and bounded (≤3 total attempts); ambiguous
  remote mutations are never automatically retried.
- WebDAV automatic HTTP mutation retry remains disabled.
- Secrets remain in the OS keyring/environment; Basic auth remains the only
  shipped WebDAV auth.

## Not in this release (intentionally deferred)

- Local directory → WebDAV recursive upload.
- Recursive WebDAV delete.
- WebDAV → WebDAV recursive or cross-target copy/move.
- Multiple simultaneous recursive roots.
- Digest/Bearer authentication (no new interoperability evidence).
- Metadata/property mutation.

## Installation

Download your preferred artifact and `SHA256SUMS` from the GitHub Release and
verify:

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

```bash
# Debian / Ubuntu
sudo apt install ./arx_0.21.0_amd64.deb

# Fedora / RHEL family
sudo dnf install ./arx-0.21.0-1.x86_64.rpm

# Portable tarball
tar xzf arx-v0.21.0-x86_64-unknown-linux-gnu.tar.gz
sudo install -m 755 arx-v0.21.0-x86_64-unknown-linux-gnu/arx /usr/local/bin/arx
```

Expected version output:

```text
arx 0.21.0
```

No configuration migration is required from v0.20.0.
