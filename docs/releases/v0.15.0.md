# ARX v0.15.0

## Remote Workspace

The hero workflow moves from concept to production: Compare two locations (local or SFTP), preview exact sync consequences, execute a frozen plan in the background, and verify the result afterwards. The lifecycle is:

```
Workspace scan → Diff → Sync Preview → Frozen Plan → Execute → Verify
```

Verification reports `Synchronized`, `DifferencesRemain`, or `Inconclusive` — not an optimistic guess. Current execution supports local → local, local → SFTP, and SFTP → local. SFTP → SFTP is intentionally blocked.

## Commander UX

- Dual-pane TUI with tabs, swap, split toggle
- Space toggles selection and advances to the next entry
- Virtual `..` parent row in every directory
- Contextual runtime footer shows available actions
- Command Center (Ctrl+P) for fuzzy search across hosts, bookmarks, history

## File Operations

| Key | Action |
|-----|--------|
| F5 | Copy — Local↔Local, Local↔SFTP (SFTP→SFTP unsupported) |
| F6 | Move — Local↔Local only |
| F7 | Create directory — Local + SFTP |
| F8 | Delete — Local: trash; SFTP: permanent confirmed (no recursive remote delete) |
| F9 | Host Center |

## Terminal & Discovery

- **Ctrl+X P** — Workspace Sync Preview (primary)
- **Ctrl+X T** — Embedded Terminal for a local right pane
- **Ctrl+P** — Command Center
- Command Center surfaces actions, hosts, bookmarks, and user menu
- Terminal lifecycle restoration after suspend

## Remote Files

- **SFTP F3** — bounded read-only text preview (1 MiB / 500 lines)
- **SFTP F4** — conflict-safe UTF-8 text editing
  - Complete file only (no truncated preview editing)
  - Binary content and NUL bytes refused
  - External remote change blocks overwrite
  - Transactional stage → backup → commit with rollback
  - Transport-ambiguous failure retains recovery evidence

## Safety

- Frozen sync plans never mutate after dispatch
- Destructive sync modes require explicit Preview confirmation
- Stale workspace diffs are revalidated before execution
- No recursive remote directory deletion
- No destructive automatic retry
- Host key verification through the user's OpenSSH

## Known Limitations

- Published binary target: **Linux x86_64 only**
- SFTP → SFTP workspace sync unsupported
- Cross-backend Move unsupported
- Recursive SFTP directory deletion unsupported
- SFTP F4 is text / UTF-8 only
- SFTP F4 obeys the current safe edit-size limit
- S3 and WebDAV backends remain non-production stubs
