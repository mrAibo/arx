# ARX v0.17.0

## SSH Host Manager — Released (SUPPORTED MVP)

ARX adds an SSH Host Manager as a **supported MVP**. ARX can now manage a
dedicated `~/.ssh/arx_hosts.conf` (installed via a single `Include`), list
unmanaged hosts discovered from `~/.ssh/config` and any `Include` globs, and
attach a generated Ed25519 key (`ssh-keygen`) — without ever storing private
key material itself.

### What works (truth-classified)

- **Managed hosts** — add / edit / delete hosts in `~/.ssh/arx_hosts.conf`,
  kept as a clean `Host`/`IdentityFile`/`IdentitiesOnly` file. ARX stores the
  key *path* only, never key bytes.
- **Unmanaged host discovery** — parse `~/.ssh/config` and resolve `Include`
  directives against the system glob (tilde expansion, relative includes
  anchored at `~/.ssh`, multi-component and nested globs).
- **Collision check** — refuse add/edit when an unmanaged `Host` alias already
  exists, so ARX never shadows a user-owned config entry.
- **Key generation** — on explicit confirm, generate `~/.ssh/arx/<alias>_ed25519`
  via `ssh-keygen`, attach it, and roll back both key files on any failure
  (correctly appending `.pub`, not replacing the extension — dotted aliases
  like `prod.eu` are handled).
- **Fail-closed discovery** — a missing/unreadable include is an *error*
  (write refused), not a silent empty result. A wildcard match whose stat
  fails also errors rather than being dropped.

### Glob semantics

The `Include` matcher mirrors OpenSSH `glob(3)` pathname semantics:

- prefix anchored at start, suffix anchored at end, no internal overlap;
- bracket classes / ranges / negation (`[ab]`, `[1-9]`, `[!ab]`);
- leading-dot rule (a leading `.` is matched only by an explicit `.`);
- `*` combined with brackets in one component (`env-[ab]*/hosts.conf`).

### Explicitly unsupported (frozen surface)

- Editing the user's `~/.ssh/config` directly — ARX owns only `arx_hosts.conf`.
- Storing private keys — ARX stores `IdentityFile` *paths* only.
- S3 → SSH, SFTP → SSH transfer, or any cross-backend move involving SSH.
- Remote Workspace Sync with SSH hosts.

Capability surface is frozen to:
`List + Discover + Add/Edit/Delete managed hosts + Attach generated key`.

## Upgrade notes

- No config-breaking changes for existing Local / SFTP / Archive / S3 workflows.
- SSH management is opt-in: ARX installs a single `Include ~/.ssh/arx_hosts.conf`
  into `~/.ssh/config` on first use. No private keys are ever written to config.
- MSRV remains **Rust 1.88**.
